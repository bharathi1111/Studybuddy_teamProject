# 7.Project Documentation

## Epic 4: Database Configuration

The AI StudyBuddy backend uses MongoDB as its primary NoSQL database and Mongoose ODM for data modeling and schema validation. MongoDB stores user information, uploaded study materials, and AI-generated learning resources in a structured manner. Mongoose simplifies database operations by providing schemas, validation rules, and efficient query handling.

## Configure MongoDB

Install Mongoose using the following command:

```bash
npm install mongoose
```

## Create Database Connection

Before performing any database operations, establish a connection between the backend and MongoDB using Mongoose. The connection module is initialized during server startup to ensure reliable communication with the database.

## Mongoose Schema Definitions

### 1. User Schema (models/User.js)

The User schema stores authentication and profile information for registered users. It includes fields such as name, email, password, and role. Passwords are securely encrypted before being stored in the database.

### 2. Study Material Schema (models/Material.js)

![Figure 13](assets/image13.png)

The Study Material schema stores the learning content uploaded by users. This content acts as the input for AI-powered features such as summaries, quizzes, flashcards, and study plans.

## Database Collections

The AI StudyBuddy database consists of the following collections:

- **Users** – Stores user account and authentication details.
- **Study Materials** – Stores uploaded learning materials.

## API Route Interface Endpoints

The backend exposes RESTful APIs to interact with the database and AI services.

### 1. Authentication APIs

Handles user registration, login, JWT authentication, and protected route access.

### 2. Study Material APIs

Allows users to upload, retrieve, update, and manage study materials.

### 3. AI Feature APIs

Provides endpoints for:

- AI Summary Generation
- AI Flashcard Generation
- AI Quiz Generation
- AI Study Plan Generation

### 4. Administrative APIs

Provides administrator-only endpoints for managing users and monitoring system activities.

## Project Execution

The AI StudyBuddy backend can be executed locally using Node.js. Before running the application, ensure that MongoDB is running and the required environment variables are configured correctly. The backend exposes REST APIs that can be tested using Postman or Thunder Client.

### Running the Backend Server

Install all required dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

After successful execution, the server connects to MongoDB and starts listening for incoming API requests.
