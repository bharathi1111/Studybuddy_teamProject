# 2. Requirement Analysis

## Software Requirements

- **Operating System:** Windows 10/11, macOS, or Linux (supports cross-platform operations).
- **Node.js (v16 or above):** Runtime ecosystem running server logic and routing infrastructure.
- **npm (v8 or above):** Node package manager to control operational dependencies.
- **Express.js:** Lightweight routing web framework to construct backend RESTful entry points.
- **MongoDB:** Document NoSQL engine storing users, posts, categories, comments, and analytics metrics.
- **Postman:** API verification toolkit to assert schema validation responses across administrative route shields.
- **Code Editor:** Visual Studio Code or similar IDE environment.

## Hardware Requirements

- **Processor:** Intel Core i5 (8th Gen or above) / AMD Ryzen 5 or equivalent.
- **RAM:** 8 GB minimum (16 GB recommended for concurrent instances of MongoDB, processing layers, and execution nodes).
- **Storage:** 1 GB of available disk workspace.

## Functional Requirements

The system supports the following major functions:

1. User registration and secure login.
2. JWT-based authentication for protected resources.
3. Role-Based Access Control for Students and Administrators.
4. Upload and management of study materials.
5. AI-generated summaries.
6. AI-generated flashcards.
7. AI-generated multiple-choice quizzes.
8. Personalized AI-generated study plans.
9. Storage and retrieval of generated learning resources.
10. Administrator management and monitoring operations.

## User Roles and Responsibilities

### Student

Students are the primary users of the system. They can register, log in securely, upload study materials, and utilize AI-powered features such as summary generation, flashcard creation, quiz generation, and personalized study plans. Students can also view and manage their previously generated learning resources.

### Administrator

Administrators manage the overall system and ensure its smooth operation. They monitor registered users, manage user accounts, oversee application usage, maintain system integrity, and ensure that AI-powered services function correctly. Administrators also have permission to perform system-level management tasks and resolve user-related issues.

## Key Features

- **Secure User Authentication:** Implements JWT-based authentication with encrypted passwords using bcrypt for secure user access.
- **Study Material Management:** Allows users to upload and manage study materials that serve as input for AI-powered learning features.
- **AI Summary Generation:** Generates concise and easy-to-understand summaries from uploaded study content using the Google Gemini API.
- **AI Flashcard Generation:** Automatically creates flashcards from study materials to improve concept revision and active recall.
- **AI Quiz Generation:** Produces multiple-choice quizzes based on uploaded content, enabling students to test their knowledge.
- **AI Study Plan Generation:** Generates personalized study plans according to the user's learning goals and available study time.
- **Role-Based Access Control (RBAC):** Provides different access privileges for Students and Administrators to ensure secure system management.
- **MongoDB Data Storage:** Efficiently stores user information, uploaded materials, and AI-generated learning resources using MongoDB.
