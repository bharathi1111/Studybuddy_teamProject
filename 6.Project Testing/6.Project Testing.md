# 6.Project Testing

## API Testing

The backend APIs can be tested using Postman.

### 1. User Registration

Registers a new user by accepting the required details and securely storing the encrypted password in the MongoDB database.

**Endpoint:**

```http
POST /api/auth/register
```

![Figure 14](assets/image14.png)

### 2. User Login

Authenticates the registered user and generates a JWT access token for accessing protected APIs.

**Endpoint:**

```http
POST /api/auth/login
```

![Figure 15](assets/image15.png)

### 3. Upload Study Material

Allows authenticated users to upload study material that will be used as input for AI-powered content generation.

**Endpoint:**

```http
POST /api/material/upload
```

![Figure 16](assets/image16.png)

### 4. Generate AI Summary

Sends the uploaded study material to the Google Gemini API and generates a concise summary.

**Endpoint:**

```http
POST /api/materials/:id/summarize
```

![Figure 17](assets/image17.png)

### 5. Generate AI Flashcards

Creates AI-generated flashcards from the uploaded study material for effective revision.

**Endpoint:**

```http
POST /api/ai/flashcards
```

### 6. Generate AI Quiz

Generates multiple-choice questions from the uploaded study material to help users assess their understanding.

**Endpoint:**

```http
POST /api/ai/quiz
```

### 7. Generate AI Study Plan

Creates a personalized study schedule based on the user's learning goals and available study time.

**Endpoint:**

```http
POST /api/ai/study-plan
```
